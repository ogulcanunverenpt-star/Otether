ℹ️ Otether Connection & Privacy Guide

🌐 Step 1: Connect Client Device via Proxy

  • SSID: DIRECT-xx-Otether

  • Password: otether123

2. Open Wi-Fi settings on the client device and configure Manual HTTP Proxy:

  • Proxy IP / Host: 192.168.49.1

  • Proxy Port: 8080

3. Open Web Control Dashboard in any browser: http://192.168.49.1:8081

🔐 Step 2: Understand what is recorded

Otether only sees traffic that a client explicitly sends through its HTTP proxy. It records connection metadata, not message bodies or credentials.

HTTPS connections use an encrypted CONNECT tunnel. Their contents remain encrypted end-to-end; no Otether CA certificate is required or provided.

Only inspect traffic on devices and networks you own or are authorized to administer.
